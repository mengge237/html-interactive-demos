# 前端交互 Demo 集（html-interactive-demos）

50+ 个独立前端交互页面练习集，覆盖 CSS3 动画、3D 效果、粒子特效、组件动效与响应式布局。

## ✨ 内容分类

| 分类 | 页面 |
|---|---|
| 🎬 **3D / 动画** | 3danimate、3dtext、css3d、turn、tunnel、wavy、wavy2、stairway、scramble |
| ✨ **特效** | rain（雨）、star（星空）、flower（花）、element、spinner、design |
| 🧱 **组件动效** | button1-6、menu、menu2、card、card2、card3、checkbox、list、tabs |
| 🖱️ **交互** | hover、cursor、keyboard、scroll、scroll2、shadow、circle、climb |
| 🔍 **其他** | 404、404_2、calendar、capsule、glassmorphism、gsap、length、notes、rocket、text、time、travel、unfold、border、weather |

## 🛠 技术栈

- HTML5 / CSS3（动画、渐变、玻璃拟态、响应式）
- JavaScript（原生交互逻辑）
- GSAP（动效库）
- Canvas / CSS 3D 变换

## 🚀 快速开始

直接打开任意 `.html` 文件即可查看效果（纯静态，无需构建）。

## 📌 说明

- 每个页面为独立交互 Demo，适合前端动效/交互方向的作品展示与参考
- 覆盖按钮、菜单、卡片、加载、滚动、404 等常见前端场景
