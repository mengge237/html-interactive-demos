# 前端交互 Demo 集

50 个独立编写的前端交互页面合集，覆盖 CSS3 动画、3D 变换、粒子特效与组件动效，是我在 Web 交互方向的核心练习成果。

## ✨ 项目亮点

- **50 个独立页面**：每个页面聚焦一种交互/动效实现，可独立运行
- **覆盖主流前端动效技术**：CSS3 动画、3D 变换、Canvas、GSAP
- **组件级动效库**：按钮 / 菜单 / 卡片 / 加载 / 滚动 / 表单等常见组件均有实现
- **含视觉特效页**：3D 文字、玻璃拟态、粒子雨雪、星空、流体波浪等

## 🛠 技术栈

| 技术 | 用途 |
|---|---|
| HTML5 | 页面结构 |
| CSS3 | 动画、渐变、3D 变换、玻璃拟态、响应式 |
| JavaScript | 交互逻辑、DOM 操作 |
| GSAP | 高级动画 |
| Canvas | 粒子特效 |

## 🚀 本地运行

纯静态项目，无需构建：

```bash
# 方式一：直接双击打开任意 .html
# 方式二：本地起服务（推荐，避免个别页面跨域限制）
cd HTML_TRIAL
python -m http.server 8080
# 或 npx serve .
# 然后访问 http://localhost:8080
```
